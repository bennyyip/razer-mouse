Mouse vid and pid is hard-coded. Change it if you are using a different mouse.

# Usage
```
$ razer help
Avaliable commands: status, setdpi, reset, help

$ razer status
DPI: [4800, 4800]
battery: 60
active_stage: 1
stages:
1 [4800, 4800]

$ razer reset

$ razer status
DPI: [800, 800]
battery: 60
active_stage: 1
stages:
1 [800, 800]
2 [1600, 1600]
3 [3200, 3200]
4 [4800, 4800]
5 [6400, 6400]

$ razer setdpi 4800

$ razer status
DPI: [4800, 4800]
battery: 60
active_stage: 1
stages:
1 [4800, 4800]
```
